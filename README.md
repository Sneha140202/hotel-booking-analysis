# Hotel Booking Analysis

## Project Overview

A data analysis and machine learning project focused on understanding hotel booking behaviour, predicting cancellations, and optimising pricing strategies using historical booking data.

---

## Business Problem Statement

### 1. Cancellation Prediction
Hotel cancellations result in significant revenue loss and operational inefficiencies. This project aims to identify the key drivers behind booking cancellations and build a predictive model to flag high-risk bookings early — enabling hotels to implement targeted retention strategies, adjust overbooking policies, and reduce last-minute revenue leakage.

### 2. Pricing Optimisation
Dynamic pricing is critical in the hospitality industry. This project analyses booking patterns, seasonal trends, lead times, and guest segments to uncover pricing opportunities — helping hotels maximise Average Daily Rate (ADR) and Revenue Per Available Room (RevPAR) while staying competitive.

## How to Run

